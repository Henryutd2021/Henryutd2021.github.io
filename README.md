# Honglin Li — research website

Source of the personal research website, built with [Quarto](https://quarto.org).

- Hand-written pages: `index.qmd`, `research.qmd`, `software-data.qmd`, `teaching.qmd`, `cv.qmd`, `notes.qmd`.
- `projects/*.qmd` and `publications.qmd` are generated from a curated list of published work. Do not edit them by hand.
- Only the pages listed under `render` in `_quarto.yml` are published.

Build locally with `quarto preview`.
